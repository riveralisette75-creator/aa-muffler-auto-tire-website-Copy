A&A Muffler Auto & Tire website

FILES TO UPLOAD
- index.html (main webpage)
- style.css (design and mobile layout)
- logo.jpeg (business logo image)
- service-banner.png (service image)

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account and verify your email.
2. Create a PUBLIC repository named aa-muffler-auto-tire-website.
3. Upload the four files above to the repository's top level (not the ZIP).
4. Open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait a few minutes and open the URL shown on the Pages settings screen.

NOTES
- This is a static website; the phone number is clickable on mobile.
- No address, hours, pricing, or customer reviews have been invented.
- Before publishing, confirm the phone number and all service descriptions are accurate.
- GitHub Pages sites and public repositories can be viewed by anyone. Do not upload passwords or private customer information.
